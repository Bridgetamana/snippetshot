# SnippetShot

SnippetShot is a VS Code extension that lets you turn code snippets into stunning shareable images instantly.

![SnippetShot Demo](assets/snippetshot1.png)
![SnippetShot Demo](assets/snippetshot2.png)

## Features

- Displays file paths.
- Focus specific lines of code directly by clicking on them.
- Editable attribution watermark

## Getting Started

1. Open SnippetShot: Command Palette `SnippetShot`
2. Selecting automatically copies and the panel listens for paste.
3. Paste (if needed): Click into the panel and press Ctrl+V.
4. Change background, toggle line numbers, or edit the attribution watermark.
5. Click the "Save" or "Copy" button to export.
